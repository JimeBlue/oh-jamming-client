Open questions the wireframe doesn't answer

  1. Removing a photo needs an API change. image is .optional(), so in a partial PATCH undefined means "leave it alone" and "" fails the Cloudinary URL check. Replace works today; clear does not. Either widen the schema and $unset in the controller, or make the Photo modal replace-only.
  2. Is "Edit" a fourth rail item, or a button on the header card? Drawn as a rail item above — it's a place you go and come back from, so it deserves a URL and a spot in the nav. A header button is the alternative and is less discoverable.
  3. Where is "Cancel this jam"? Not on this page in the wireframe. It lives on the board and arguably on the cockpit — putting a destructive action at the bottom of an edit rail is how it gets clicked by accident.
  4. Does the pencil on the board go here, or to the cockpit? Drawn as straight here — that pencil currently goes nowhere at all.
  5. Line-up and slot length aren't in your original list but the API allows them while nothing is booked. Shown as a second group; drop the group entirely if you'd rather keep the scope to the six you named.
